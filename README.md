# NFL Hub

One NFL app with one entry point: season probabilities and stat leaders, a live game companion, and player analytics. Built for reliability first.

**Status: foundation built (M0).** Five odds and forecast sources are captured twice a day and nflverse data is downloaded and checked; the site shows only a data status page so far. The design and build plan are in [docs/PLAN.md](docs/PLAN.md); when data breaks, see [docs/RUNBOOK.md](docs/RUNBOOK.md).

Live: https://daniel-beachy.github.io/nfl-hub/
