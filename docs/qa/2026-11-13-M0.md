## Summary

- **Blockers: 1.** QA-M0-1: one hanging ESPN endpoint makes capture outlive its 10-minute job timeout, so no source is saved that day.
- **Majors: 7.**
  - QA-M0-2: all sources down reads as `degraded`.
  - QA-M0-3: a renamed optional price field gives silently changed values marked `ok`.
  - QA-M0-4: wrong values survive in partial metrics.
  - QA-M0-5: all-zero awards pass as ok.
  - QA-M0-6: `gamesInProgress` is frozen at the first run.
  - QA-M0-7: Polymarket and Kalshi shape errors are labeled `internal` and the raw payload is lost.
  - QA-M0-8: a crash in `health.ts` is invisible.
- **Minor: 6** (QA-M0-9 to QA-M0-14). **Polish: 1** (QA-M0-15).

My recommendation: fix QA-M0-1 before the three-day unattended checkpoint starts, because a hang during that window would cost a whole day. QA-M0-2, QA-M0-6 and QA-M0-8 are small changes worth making at the same time. QA-M0-3 to QA-M0-5 matter before M1 charts any of this data.

ID: QA-M0-4
Severity: major (blocker-class once M1 charts partial blocks)

  Actual: values that are still ≤ 1 after ×100 are kept. 14 to 17 teams per source survive with values 100× too big

  sum-checked. Their kept sum is 2.5 to 7.5 for a group that must sum to about 1.
  More generally: an incomplete group (any team missing or dropped) skips both the sum check and de-vig, so its

Fix ideas: drop the whole metric when any value is out of range (a range error is a parse bug, not one bad team);
  check incomplete groups against the upper bound (a subset can never sum above 1.6); record per metric whether it
  was normalized so the consensus never mixes raw and de-vigged values.

## Other observations

- **Concurrency group and test dispatches.** A `workflow_dispatch` that is waiting is replaced by any later push run in the `daily` group (run 43570335259 was cancelled by an M1-1 push). This does not matter for real captures, because every push run captures too, but forced-failure tests have to be run when nobody is pushing.
- **Load when a source is fully down.** Kalshi makes 60 requests and DraftKings, if athletes fail, up to about 430. Both are fine against public APIs, but worth keeping in mind with QA-M0-1.
- **`npm run check` fails locally while a worktree session exists.** A session working in `.claude/worktrees/<name>/` puts a second `tsconfig.json` inside the checkout, and `eslint .` then fails with 114 "multiple candidate TSConfigRootDirs" parsing errors. CI is not affected. Fix: add `.claude/**` to the ignores in `eslint.config`. For this commit the same checks ran with `--ignore-pattern '.claude/**'`: typecheck, lint and build clean, 191 tests green.
- **Bovada 2026-11-14:** MVP and Coach of the Year were taken off the board between 06:05 and 07:13 UTC. If they are still missing on 2026-11-16, the bonus-tier issue should open by itself, which is a free live test of P11 during the checkpoint.
